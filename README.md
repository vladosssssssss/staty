# Contrabas · Облікова книга (міні CRM)

Три файли — це сайт (`index.html`, `style.css`, `config.js`, `app.js`).
Один файл — це бекенд для Google Таблиці (`Code.gs`).

## 1. Google Sheets + Apps Script (робиться один раз)

1. Створи нову Google Таблицю: sheets.new (можна лишити її повністю порожньою).
2. Розширення → Apps Script.
3. Видали весь код у `Code.gs`, який там за замовчуванням, і встав вміст файлу `Code.gs` з цього архіву.
4. Збережи (значок дискети або Ctrl+S).
5. Розгорнути (Deploy) → Нове розгортання:
   - Тип: **Веб-застосунок (Web app)**
   - Опис: будь-який
   - Виконати від імені (Execute as): **Я (твій акаунт)**
   - Хто має доступ (Who has access): **Усі (Anyone)**
6. Натисни «Розгорнути», дозволь доступ своєму акаунту (перший раз Google попросить підтвердження — це нормально, тисни «Додатково» → «Перейти на... (небезпечно)», бо це твій власний скрипт).
7. Скопіюй посилання, що закінчується на `/exec`.

Якщо ти вже маєш деплой (лінк, який дав мені) — просто онови його код: відкрий той самий Apps Script проєкт → встав `Code.gs` → **Розгорнути → Керувати розгортаннями → значок олівця → Нова версія → Розгорнути**. Просто зберегти файл недостатньо, потрібно оновити саме версію розгортання.

Перший же запит із сайту сам створить листи `Leads`, `Payments`, `Payouts`, `Settings` і заповнить стартові тарифи/ціни/відсотки — нічого руками створювати в таблиці не треба.

## 2. Сайт

1. Відкрий `config.js` і встав своє посилання `/exec` у `BACKEND_URL` (за замовчуванням там уже стоїть те, що ти прислав — якщо це той самий деплой, можна нічого не міняти).
2. Заливай усі 4 файли (`index.html`, `style.css`, `config.js`, `app.js`) на будь-який хостинг: GitHub Pages, Netlify, Vercel, або навіть відкривай `index.html` просто подвійним кліком локально — теж працює, окремого сервера не треба.
3. Готово. При відкритті сайт сам підтягне всі дані з таблиці.

## Як влаштована логіка

- **Напрямки / тарифи / ціни / % комісії** — редагуються у вкладці «Тарифи та ціни». Відсоток закріплений за парою «напрямок + тариф» і не залежить від того, яку саме ціну (знижку) обрав клієнт.
- **Лід** = ім'я + нік + напрямок + тариф + обрана ціна + статус. Створюється кнопкою «+ Новий лід», можна одразу внести перший платіж.
- **Платежі** — до одного ліда можна додавати скільки завгодно платежів (кнопка «+ Додати платіж» усередині картки ліда) — для розстрочки на 2-3-4 внески. Кожен платіж можна скасувати (наприклад, клієнт зробив повернення) — сума одразу повертається у «залишок» ліда, сам платіж лишається в історії позначений як скасований.
- **Місяць** — таблиця лідів показує ліди, створені у вибраному місяці (стрілки ‹ › або календар зверху). Пошук (за ім'ям/ніком/номером) шукає по всій базі, незалежно від місяця — бо лід міг прийти в одному місяці, а доплатити в іншому.
- **Комісія** рахується формулами:
  - «Мій факт» по ліду = сума зарахованих платежів × % тарифу.
  - «Потенціал» по ліду = (ціна тарифу − сплачено) × % тарифу — тобто скільки ще можеш заробити з цього ліда, якщо довиплатить.
- **Верхня панель** (усе, крім останнього блоку, показує дані лідів обраного місяця — тих самих, що й у таблиці нижче):
  - **Гроші клієнтів** — окремо: скільки клієнти вже сплатили фактично, і скільки повинні сплатити повністю за тарифом (якщо клієнт вніс 200 € з 1000 €, тут буде 200 € і 1000 € — саме так, як ти й описував).
  - **Мої гроші** — окремо: моя комісія з того, що вже сплачено (факт), і моя комісія з повної суми тарифу, якби клієнт довиплатив усе (потенціал). Відсоток завжди береться від тарифу конкретного ліда.
  - **Розрахунки з тобою**: «Очікується виплата» = скільки ти вже заробив за весь час мінус те, що тобі вже виплатили (вкладка «Виплати ЗП»). І окремо, з підсвіткою — скільки грошей клієнти реально занесли в касу цього місяця (за датою самого платежу, а не датою створення ліда) плюс твій % з цього в € і ₴.

## Оновлення (виправлено: лід зникав з історії місяця)

Причина була в тому, що Google Sheets сам перетворював текстове значення місяця («2026-08») на дату при записі в таблицю, і порівняння «цей лід належить обраному місяцю» ламалося. Тепер:
- місяць завжди рахується наново з дати створення ліда (а не з окремої колонки), і на бекенді, і на сайті;
- колонки з датами примусово тримаються як текст, щоб Sheets більше їх не чіпав.

**Обов'язково онови деплой Apps Script** (вклади новий `Code.gs` → Розгорнути → Керувати розгортаннями → олівець → Нова версія → Розгорнути), інакше сайт продовжить ходити у старий, неполагоджений код.

## Якщо щось не підвантажується

- Індикатор зверху праворуч покаже статус з'єднання. Червона крапка = проблема з `BACKEND_URL` або деплой Apps Script не оновлений/не публічний.
- Головна причина «CORS» помилок для Apps Script — деплой не типу «Веб-застосунок» з доступом «Усі», або забули натиснути «Нова версія» після зміни коду. Сам сайт CORS-заголовків не потребує — запити йдуть як «прості» POST, без preflight.
